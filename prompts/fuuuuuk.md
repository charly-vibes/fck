description: "Frustration with a tunable dial. Usage: /fuuuuuk [0-5] — more u's, more urgency."
---

Run the `fck` skill at intensity $ARGUMENTS. If no argument is given, use 3.
If the argument isn't a plain number (or is out of range), clamp it into 0–5
if there's an obvious number in there, otherwise fall back to 3 rather than
guessing at intent. Let the number scale how much you investigate before
responding — not how dramatic you sound. (`/fuuuuuk 0` is deliberately
equivalent to `/fuck` — that's not a bug, it's the bottom of the same dial.)
